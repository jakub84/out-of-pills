## Notes

Roadmap S-07 (FR-010, FR-012): user can edit a medication (including its dosage) and pause / resume it; from that moment the calculation follows the new values, and a paused medication does not decrease. Risk: changes to dosage and pause state must not retroactively alter pills already consumed — calculation over time segments.
